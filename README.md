# 田島二丁目の整骨院 LP

田島二丁目の整骨院向けの仮公開ランディングページです。

## 現在の状態

- 静的HTMLのみで動作
- PC・スマートフォン対応
- 未確定の診療情報は「準備中」として表示
- 検索エンジンには `noindex` を指定

## 本公開前に差し替える項目

1. 正式な院名
2. 住所・地図URL
3. 電話番号・LINE URL
4. 診療時間・休診日
5. 施術メニュー・料金
6. 保険取り扱いの案内
7. 実際の院内・スタッフ写真
8. `noindex` の解除

## ローカル確認

`index.html` をブラウザで開くか、任意の静的サーバーで配信してください。
